# 🛍️ Coupons Souq

**Coupons Souq** is a modern discount coupons and shopping platform that helps users save money while discovering the latest offers and products from top brands.  
The app provides exclusive promo codes, real-time deals, and a seamless shopping experience — all in one place.

---

## ✨ Key Features

- 🔖 Browse and redeem **exclusive discount coupons** from leading brands.  
- 🛒 Discover and **shop trending products** directly within the app.  
- 💸 Enjoy **daily deals** and time-limited offers.  
- ❤️ Save favorite products and brands for quick access.  
- 🔍 Smart search and category filtering.  
- 🌐 Multi-language support (Arabic & English).  

---

## ⚙️ Tech Stack

- **Flutter** (Android & iOS)
- **Bloc / Cubit** for state management
- **Dio + Retrofit** for API integration
- **Clean Architecture & SOLID Principles**
- **Firebase** (Analytics & Notifications)
- **Branch.io** for deep linking & smart sharing
- **Clarity Analytics** for user behavior tracking
